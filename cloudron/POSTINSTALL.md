SEO Playground is installed. Only Cloudron users can open it: Cloudron's login screen sits in front of the app.

1. Open the app and go to **Settings** to enter your DataForSEO login and password (or API key). They are stored in the app's database, which is part of the Cloudron backups.
2. Everything you run is billed by DataForSEO, so grant access to people you trust with that credit.

Your data lives in `/app/data` (one SQLite file per project). The scheduled Geo-grid and Prompt Tracker checks run inside the app, so there is nothing else to configure.
